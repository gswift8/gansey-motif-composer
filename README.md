# Gansey Studio v0.11.0 — Workspace Navigation Phase

This release begins the workspace-navigation phase.

Each band in Section 3 now has:
- jump-to-start and jump-to-end buttons
- left and right scroll buttons
- a larger visible horizontal scrollbar
- mouse-wheel and trackpad horizontal scrolling
- fixed-width motif cards that remain readable
- automatic scrolling to newly added motifs

Existing motif and spacer cards are still reordered with Move Left and Move Right.
Dragging motifs from the motif library into a band remains supported.

For a browser-only GitHub update, upload everything inside this release folder to
the repository root and allow GitHub to replace matching files. Keep the `css/`
and `js/` folders intact.
