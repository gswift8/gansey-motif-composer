# Gansey Studio v0.11.1 — Section Composer Scrolling Fix

The horizontal scrollbar now belongs to the whole **3. Section composer** workspace,
rather than only to an individual motif strip.

## What changed

- The complete section-card workspace expands as motifs are added.
- A large scrollbar appears at the bottom of Section 3.
- Top controls scroll left, right, to the beginning, or to the end.
- Mouse-wheel and trackpad movement over the workspace scroll horizontally.
- Band-level arrow controls now move the entire Section 3 workspace.
- Newly added motifs automatically reveal at the right edge.

For the browser-only GitHub workflow, extract the ZIP and upload everything inside
the release folder to the repository root. Let GitHub replace matching files and
keep the `css/` and `js/` folders intact.
